ME-PHYS-14 · Offline 3D trajectory unit adapter

CONVERSION ONLY — NOT CALIBRATED OR LICENSED FOR GAME USE. A private, local-only parser can validate a user-supplied ground-truth CSV excerpt from the documented Soccer Ball 3D format. It converts x/y/z from decimeters to meters and frame numbers into seconds using the sequence's measured FPS, preserving track IDs and rejecting missing headers, duplicate frames and malformed values.

No file-upload interface, remote dataset fetch or source repository import is enabled. Ball identity, angular spin, commercial permission and aerodynamic coefficients remain unverified; any converted trajectory is a structural candidate for independent academic inspection, not a calibration of the universal Football Architect ball. See the upstream data conventions and non-commercial licensing.

ME-PHYS-15 · Independent 3D trajectory error protocol

SCIENTIFIC HOLD — NO VERIFIED REAL FLIGHT HOLDOUT. An offline, synthetic-tested evaluator calculates 3D MAE/RMSE, per-axis RMSE, maximum error, endpoint error and translation-invariant displacement RMSE when observed and predicted trajectories use the same verified xyz axes, metres and time origin. Linear interpolation of 60 Hz predictions onto observation timestamps is bounded and never extrapolates or bridges large gaps.

The evaluator never rotates, scales or shifts measurements to hide discrepancies. A displacement-only metric can remove a constant translation, but not axis, clock, camera or physical-model errors. Flight-phase selection, camera uncertainty, independently measured launch spin, original acquisition independence and commercial-use rights must be verified outside this numerical routine. No simulated self-comparison is evidence of real-world accuracy; no user dataset loaded, coefficient approved or game physics changed.
