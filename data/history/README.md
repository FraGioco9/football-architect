# Competition History

No canonical historical results are currently available. Public History therefore shows its localized empty state.

Local History reuses `tools/dev-standings-preview-data.mjs` while the existing fictional-standings debug setting is active. Its four completed preview seasons and team records are explicitly fictional. Player record cards remain empty because no historical player statistics are available, including in debug mode. Never copy these generated results into this directory or publish them as official results.

When authoritative results become available, store one approved completed final table per competition and season, using canonical competition/club IDs, provenance and coverage metadata. Derive champions, archive, season detail and records from that single source. Validate membership, ranking, statistics and the rules applicable to each season before publication.
