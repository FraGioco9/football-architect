# NAV-01 — Sidebar Evolution (implementation specification)

Status: Draft / implementation pending. This document does not claim a working UI.

## Verified baseline
- main at branch creation: 4cbc5b1812cf057b9a43ac639a93a2962fb6cf46.
- Existing navigation source: templates/app-page.html; style: assets/app.css; translations/routing: assets/app.js.
- Static pages generated by tools/generate-app-pages.mjs.
- Avoid overlapping in-flight PR #240 (club pages), #252 (Calendar DEV season link) and #253 (international cups).

## Approved information architecture
- Home: Dashboard, Calendar.
- Competitions: top-level navigation to existing /competitions; independent expand/collapse control. Domestic and International sub-navigation/anchors within canonical competitions page, without duplicating routes.
- Football World: Clubs, new canonical app route /clubs (hosted app subdomain; local /app equivalent must retain existing normalization behavior).
- Utilities: Guide and Settings.
- Players: future capability only; do not display an inert item.

## Clubs directory
- Index all 320 canonical entries from data/clubs.json, without changing data.
- Search canonical club name and city; filter country, division and active/inactive; deterministic alphabetical ordering.
- Render approved crest where available; fallback consistent with existing club pages and reserve stable space.
- Each club links to its existing canonical detail path.
- Reflect absence of actual competitions or results; no fabricated sporting data.

## Interaction/accessibility
- Navigation must be keyboard-usable; visible focus; aria-current only on actual destinations.
- Competition expansion button separate from the navigation anchor, aria-expanded and aria-controls.
- Current competition descendant expanded by default; other state persists only within current session.
- Mobile must preserve the existing compact rail behavior and expose accessible nested navigation.
- No sidebar horizontal overflow at 320, 390, 768, 1440 px.
- Five translations: EN (default), DE, ES, FR, IT.
- Keep both theme modes.

## Implementation guardrails
- Generated HTML must be committed consistently with changed template/generator sources.
- Preserve existing domestic competitions, club detail pages, Calendar season-link behavior, and new international cups from PR #253.
- No workflow, database, deployment, published content, simulated results or WORLD-TIME model changes.
- Before merging: current-main reconciliation, generated-file consistency, automated tests, desktop/mobile browser QA and all exact-HEAD CI checks green.
- Draft only: never merge or deploy without separate authorization.
