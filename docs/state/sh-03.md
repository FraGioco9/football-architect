## Current world, viewed state and Debug contract

Validated D1/API `generation`, `revision`, `seasonNumber`, `day` and `phase` determine global sporting authority. **Season 0 is the unstarted world**, not a completed season. Route-selected viewed season, round/day and tab are presentation only; browser time or a fictional protected Debug clock cannot manufacture public official data. Switching between API and protected Debug invalidates stale in-flight reads; reset and URL Back/Forward must not commit wrong-source results. Failed/unavailable API reads stay truthful UNKNOWN/unavailable instead of filling fake results. Actual lifecycle changes require separate authenticated Worker/D1 commands, never presentation selection. ## Contracts

Global world: immutable generation/revision/seasonNumber/day/phase from validated API, never inferred from URL, browser time or sporting fixtures. Debug progress: isolated protected clock, never API authority. Viewed season and selected round/day: router-owned presentation only. A source revision invalidates in-flight work, including OFF→ON→OFF. A sporting read commits only after before/payload/after worlds agree and its current selection lease still matches. Empty/unavailable payloads retain real provenance and cannot invent sporting values.
