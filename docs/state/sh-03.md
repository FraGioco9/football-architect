Protected preview is an authorized isolated source, including its empty Season 0. An explicit Debug switch persists ON/OFF independently of preview progress: ON reads only isolated fixtures, OFF reads only the authoritative API without resetting either world. Source transitions update existing pages without navigation. The same switch and progress controls are available on the eight app page families, including the Clubs directory. A missing Debug clock in that source never activates public data. Public mode (Debug OFF) reads only API world; missing API data stays unavailable. No discarded #340/#342 code is reused. Static catalogues, rules, identities and crests do not depend on API success.

## Contracts

Global world: immutable generation/revision/seasonNumber/day/phase from validated API, never inferred from URL, browser time or sporting fixtures. Debug progress: isolated protected clock, never API authority. Viewed season and selected round/day: router-owned presentation only. A source revision invalidates in-flight work, including OFF→ON→OFF. A sporting read commits only after before/payload/after worlds agree and its current selection lease still matches. Empty/unavailable payloads retain real provenance and cannot invent sporting values.
