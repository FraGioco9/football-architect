Overview exposes canonical identity, translated description, stadium, colors and provisional allocation. Other views contain localized empty states. There is no new season or simulation state.

1. Audit main, merged ROUTE-02, source data, shell, publication gates and baseline tests.
2. Add failing contracts for 320 identities, 1600 routes, redirects, source fidelity and generation.

5. Extend DEV and public routing for validated club paths only. Support base, trailing slash and index.html legacy URLs; normalize legacy view queries and remove temporal parameters from Overview and History. Preserve Fixtures/Stats queries without creating state.
6. Extend the exact publication contract and matching manual publisher predicate, preserving all authorization, source SHA, artifact, project and Preview-only checks.
7. Add browser QA for desktop/mobile, themes, languages, keyboard, refresh, crest errors and competition links. Run full regression suite, generator parity and diff audit.
