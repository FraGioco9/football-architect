    Relegation play-out

    League phase, rank 13 vs League phase, rank 14. 2 leg(s). The club with the better original table rank hosts the return leg; the other club hosts first. A tie winner keeps its own original rank. Aggregate score; no away-goals rule. If level after the return leg, extra time and then penalties decide the winner.

    Winner: Remain in this division.

    Loser: Relegated.

    No points-gap threshold applies to the configured knockout ties.
